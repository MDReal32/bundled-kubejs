**Step 1: Install Java 21 JDK**

Check if Java 21 is already available:
```bash
java -version 2>&1
```

If Java is not installed or is not version 21, install Eclipse Temurin JDK 21 using winget:
```bash
winget install EclipseAdoptium.Temurin.21.JDK --accept-package-agreements --accept-source-agreements
```

If winget fails or is not available, download directly:
- URL: `https://api.adoptium.net/v3/binary/latest/21/ga/windows/x64/jdk/hotspot/normal/eclipse`
- Install the MSI and ensure it adds to PATH.

After installation, verify Java 21 is on PATH. You may need to reload the shell or set JAVA_HOME explicitly:
```bash
export JAVA_HOME="/c/Program Files/Eclipse Adoptium/jdk-21.0.7.6-hotspot"  # adjust version
export PATH="$JAVA_HOME/bin:$PATH"
java -version  # should show openjdk version "21.x.x"
```

If the foojay-resolver-convention plugin in settings.gradle.kts is working, Gradle may auto-provision Java 21 even without it on PATH. Try running `./gradlew --version` first to see if Gradle bootstraps.

Run the Gradle build from the `bundled_kubejs_dev/` directory. The first run will take 60-180 seconds as Gradle downloads NeoForge, Kotlin, and all transitive dependencies.

**Step 1: Verify Gradle wrapper works**
```bash
cd C:/Projects/bundled-kubejs/bundled_kubejs_dev
./gradlew --version
```
This should print Gradle 8.10.2 and JVM 21.x.x. If it fails:
- Check `JAVA_HOME` is set correctly
- Check `gradle-wrapper.properties` has the correct `distributionUrl`
- Check `gradle-wrapper.jar` exists and is non-empty (>50KB)

**Step 2: Verify Gradle can parse the build script**
```bash
cd C:/Projects/bundled-kubejs/bundled_kubejs_dev
./gradlew tasks --all
```
This validates BUILD-01 (build.gradle.kts is valid), BUILD-02 (settings resolved), and BUILD-04 (plugins load). If this fails, the error output will indicate which configuration block has issues.

**Step 3: Run full build**
```bash
cd C:/Projects/bundled-kubejs/bundled_kubejs_dev
./gradlew build
```
This is the BUILD-05 validation. Expected outcome: `BUILD SUCCESSFUL` with no errors.

**If the build fails**, check these in order:
1. Plugin resolution failure (Pitfall 4): Verify `maven.neoforged.net` is in `settings.gradle.kts` pluginManagement
2. Dependency resolution failure: Verify `thedarkcolour.github.io/KotlinForForge` Maven is in `build.gradle.kts` repositories
3. Kotlin version conflict (Pitfall 5): Verify `kotlin("jvm") version "2.0.21"` aligns with KFF 5.7.0
4. Java version error (Pitfall 3): Verify `java -version` shows 21.x

**Step 4: Verify dependency resolution**
```bash
cd C:/Projects/bundled-kubejs/bundled_kubejs_dev
./gradlew dependencies --configuration compileClasspath | grep kotlinforforge
```
Should show `thedarkcolour:kotlinforforge-neoforge:5.7.0` in the dependency tree.

If all steps pass, BUILD-05 is satisfied.
