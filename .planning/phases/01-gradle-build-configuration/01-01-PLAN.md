Create three Gradle configuration files with the EXACT content specified below. These are sourced from the research document which synthesized them from the official NeoForge MDK and community examples.

**File 1: `bundled_kubejs_dev/settings.gradle.kts`**
```kotlin
pluginManagement {
    repositories {
        gradlePluginPortal()
        mavenLocal()
        maven(url = "https://maven.neoforged.net/releases")
    }
}

plugins {
    id("org.gradle.toolchains.foojay-resolver-convention") version "1.0.0"
}

rootProject.name = "bundled_kubejs_dev"
```

Key points:
- `pluginManagement` block MUST include `maven(url = "https://maven.neoforged.net/releases")` or ModDevGradle plugin will not resolve (Pitfall 4 from research)
- `foojay-resolver-convention` enables auto-download of JDK 21 if not found
- `rootProject.name` MUST be `"bundled_kubejs_dev"` (BUILD-02)

**File 2: `bundled_kubejs_dev/gradle.properties`**
```properties
# Gradle performance
org.gradle.jvmargs=-Xmx1G
org.gradle.daemon=true
org.gradle.parallel=true
org.gradle.caching=true
org.gradle.configuration-cache=true

# Minecraft / NeoForge versions
minecraftVersion=1.21.1
minecraftVersionRange=[1.21.1]
neoVersion=21.1.222
neoVersionRange=[21.1,)
loaderVersionRange=[1,)

# Kotlin for Forge
kffVersion=5.7.0
kffVersionRange=[5.7,)

# Mod metadata
modId=bundled_kubejs_dev
modName=Bundled KubeJS Dev
modVersion=1.0.0
modGroupId=dev.bundledkubejs
modLicense=All Rights Reserved
```

Key points:
- ALL versions are pinned -- no `+`, `latest.release`, or `SNAPSHOT` suffixes (BUILD-03)
- `neoVersion=21.1.222` matches NeoForge for Minecraft 1.21.1
- `kffVersion=5.7.0` confirmed compatible with NeoForge 21.1.222

**File 3: `bundled_kubejs_dev/build.gradle.kts`**
```kotlin
plugins {
    id("java-library")
    id("maven-publish")
    id("net.neoforged.moddev") version "2.0.141"
    id("idea")
    kotlin("jvm") version "2.0.21"
}

val modId: String by project
val modVersion: String by project
val modGroupId: String by project

project.version = modVersion
project.group = modGroupId

base {
    archivesName.set(modId)
}

java {
    toolchain {
        languageVersion.set(JavaLanguageVersion.of(21))
    }
}

neoForge {
    version = project.property("neoVersion") as String

    runs {
        create("client") {
            client()
        }
        create("server") {
            server()
            programArgument("--nogui")
        }
    }

    mods {
        create(modId) {
            sourceSet(sourceSets.main.get())
        }
    }
}

repositories {
    maven {
        name = "Kotlin for Forge"
        url = uri("https://thedarkcolour.github.io/KotlinForForge/")
    }
}

dependencies {
    implementation("thedarkcolour:kotlinforforge-neoforge:${project.property("kffVersion")}")
}

tasks.withType<ProcessResources>().configureEach {
    val props = mapOf(
        "minecraft_version" to project.property("minecraftVersion"),
        "mod_id" to modId,
        "mod_version" to modVersion,
        "neo_version_range" to project.property("neoVersionRange"),
        "loader_version_range" to project.property("loaderVersionRange"),
        "kff_version_range" to project.property("kffVersionRange")
    )
    inputs.properties(props)
    filesMatching("META-INF/neoforge.mods.toml") {
        expand(props)
    }
}

tasks.withType<JavaCompile>().configureEach {
    options.encoding = "UTF-8"
}

idea {
    module {
        isDownloadSources = true
        isDownloadJavadoc = true
    }
}
```

Key points:
- `net.neoforged.moddev` version `2.0.141` (BUILD-01, BUILD-04)
- `kotlin("jvm") version "2.0.21"` (BUILD-04)
- NeoForge version is set via `neoForge { version = ... }` block -- NOT as a dependency (anti-pattern from research)
- `kotlinforforge-neoforge` dependency uses `kffVersion` from gradle.properties
- `ProcessResources` expands template variables into `neoforge.mods.toml` (used in Phase 2)
- Java toolchain set to 21 (required for Minecraft 1.21.1)
